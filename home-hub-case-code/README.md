# Home Hub — ZOND brand case

Static responsive case-study website. Open `dist/index.html` in a browser. No installation or build required. All 23 generated images are local WebP files in `dist/assets`. The image lightbox supports Escape and arrow keys.

## Content
Ukrainian page: About, Task, Solution, Brandbook, Applications, Result, Testimonial. Home Hub identity and all images are concept work generated for this presentation. No factual sales outcomes are claimed. The testimonial is explicitly a demo, to be replaced with an approved client quote.

## Editing
Page: dist/index.html. Styles: dist/style.css. Lightbox: dist/script.js. Images: dist/assets/. The displayed brandbook spreads are visual mockups, not a complete production-ready brand guideline document.

## Reference
Case storytelling inspired by https://www.taktika.agency/all-cases/masterzoo ; ZOND page chrome adapted from the previously approved service page.
