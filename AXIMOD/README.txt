AXIMOD — код сайту та зображення

На проді публікується з public/aximod/ за адресою https://zond.agency/aximod/
Сторінка прихована від індексації (noindex + robots Disallow).

Ця папка — вихідний пакет. Робоча копія для сайту: public/aximod/
Для локального перегляду окремо: python3 -m http.server 8000
Потім відкрийте http://localhost:8000

Форма брифу завантажує TXT-файл локально; серверного надсилання заявки немає.
Версія: 16.10.2026, чотири картки поршнів в один ряд на десктопі.
